FAQ

What is JavaScript?

JavaScript is a programming language that runs in the browser. It makes web pages interactive: it can react to clicks, check forms and change the page without reloading it.

How is the JS file connected to the page?

With the <script src="script.js"></script> tag at the end of the <body>. Placing it at the end means all HTML elements already exist when the script runs.

What is an event listener?

addEventListener attaches a function to an element. The function runs when the event happens, for example click, submit or keydown.

How does this accordion work?

All answers have max-height: 0 by default, so they are hidden. A click on a question sets max-height to the real height of the answer, and CSS transition animates the change. A second click sets it back to 0.
